# SolidWorks

> Dassault Systemes' desktop mechanical CAD system — the incumbent whose proprietary native
> format and installed base define the interoperability problem.

## What it is

Long-dominant desktop parametric MCAD. Its native `.sldprt` / `.sldasm` formats are
proprietary and cannot be read by other systems without translation
[[capvidia-step-application-protocols]].
