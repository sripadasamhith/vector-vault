# Autodesk Fusion

> Autodesk's cloud-attached MCAD/CAM system (formerly Fusion 360) — the middle point
> between desktop SolidWorks and fully cloud-native [[onshape]].

## What it is

A desktop application with cloud-backed data management: files live in Autodesk's cloud by
default and the application expects an account and connectivity.
