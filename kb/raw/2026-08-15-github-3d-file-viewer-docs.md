## Supported formats

"GitHub can host and render 3D files with the *.stl* extension." STL is the only 3D format
supported for rendering.

## Size limit

Files larger than 10 MB cannot be displayed: "files that are larger than 10 MB are too big
for GitHub to display."

## Viewer features

Click and drag to rotate, right-click and drag to pan, scroll to zoom, and change view
modes.

## Visual diff

The documentation does not describe any support for comparing versions of 3D files. The
listed interactions are viewing interactions only — there is no side-by-side or overlay
diff for STL.
